# Jaffle Analytics (dbt + BigQuery)

Learning project: transforming raw e-commerce data into tested, documented
models with dbt Core on BigQuery.

**Status:** In progress — Step 1 of my Analytics Engineer learning path.

## Stack
- dbt Core
- Google BigQuery (sandbox)
- GitHub

## Coming next
- Staging models (sources → clean views)
- Mart models (`dim_customers`, `fct_orders`)
- Data tests and documentation





Welcome to your new dbt project!

### Using the starter project

Try running the following commands:
- dbt run
- dbt test
